# Sistema-de-Controle-de-Acesso-com-Iluminação-Adaptativa

Projeto final desenvolvido para a disciplina de **Sistemas Embarcados I (ELE15942)**, referente ao semestre letivo **2025/2**. 

Este repositório contém o código-fonte e as configurações necessárias para simular e executar o sistema de controle de acesso integrado a uma lógica de iluminação adaptativa.

---

## 🛠️ Pré-requisitos e Ambiente de Desenvolvimento

Para garantir que o código compile e a simulação funcione corretamente, é necessário preparar o seu ambiente de desenvolvimento. Certifique-se de ter as seguintes ferramentas instaladas:

*   **Editor de Código:** [Visual Studio Code (VS Code)](https://code.visualstudio.com/)
*   **PlatformIO IDE:** Extensão do VS Code necessária para o gerenciamento do framework, compilação do código e controle de bibliotecas.
*   **Wokwi Simulator:** Extensão do VS Code utilizada para emular o hardware e rodar o projeto virtualmente.
*   **Framework Base:** O projeto utiliza a estrutura do **Arduino** (a biblioteca base `<Arduino.h>` é configurada automaticamente pelo PlatformIO).
